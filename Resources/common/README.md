# Neutral surface

`neutralSurface.bmp` is an opaque white 8 x 8 palette generated by
`tools/generate_neutral_surface.py` without reading any external image.
It allows material and particle colours to define the appearance, replacing
the school sample ball design in default textures and fallback paths.
The legacy `monsterBall` VFX texture identifier is kept as a compatibility
alias for this neutral surface; it does not load the former image.
