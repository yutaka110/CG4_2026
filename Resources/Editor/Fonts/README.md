# Editor fonts

`MPLUSRounded1c-Medium.ttf` (weight 500 / 中字) is the default proportional
Editor UI font. `MPLUSRounded1c-Regular.ttf` (weight 400) remains available in
the **Editor Fonts** panel. Both are distributed by the Google Fonts project
under the SIL Open Font License 1.1; the complete license is stored in
`OFL-MPLUS.txt`.

Additional licensed `.ttf`, `.otf`, or `.ttc` files can be placed here and
selected from the **Editor Fonts** panel. Subdirectories are supported. Verify
redistribution, embedding, modification, and commercial-use rights before
adding another font. Files larger than 64 MiB and paths outside this directory
are rejected. Saved changes take effect after restarting the Editor so the
DX12 font atlas is rebuilt before frames are submitted.
