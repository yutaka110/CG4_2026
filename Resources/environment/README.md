# Canyon reflection environment

`canyon_soft_256.dds` is an original procedural environment generated by
`tools/generate_canyon_environment.cpp` with AI coding assistance on 2026-09-29.
No photograph, airport image or third-party art is sampled.

The directional field smoothly blends dark earth below, sandstone around the
horizon, hazy light and muted blue sky above. A broad light lobe gives metal
some variation without recognizable scenery, sharp highlights or noise. This
is a deliberately soft reflection approximation, not a live scene capture or
a physically prefiltered roughness-dependent IBL map.

- 256 x 256 pixels per face, Direct3D cube order (+X, -X, +Y, -Y, +Z, -Z).
- 6 faces, 9 mip levels, BC6H unsigned float (linear radiance).
- 524,596 bytes including DDS header (about 0.5003 MiB).
- Uses the existing environment-map binding and reflection strength.
- Replaces `rostock_laage_airport_4k.dds` in runtime loading and the submission
  resource allowlist. The old development file is retained but not loaded.

## Regeneration

First build Release/x64 to produce the bundled DirectXTex library. From the
repository root in an x64 Visual Studio Developer Command Prompt:

```bat
cl /nologo /std:c++20 /EHsc /O2 /MT /Iexternals\DirectXTex tools\generate_canyon_environment.cpp /Fooutputs\generate_canyon_environment.obj /Feoutputs\generate_canyon_environment.exe /link ..\generated\outputs\Release\DirectXTex.lib ole32.lib windowscodecs.lib d3d11.lib dxgi.lib
outputs\generate_canyon_environment.exe
```

The generator loads its saved DDS again, verifies cube dimensions, format and
mip count, decompresses it and bounds RGB error against the original float
field to 0.03. DirectXTex is the existing MIT-licensed project dependency;
retain its notices with the submission. There is no runtime generation cost.
